# lm-basics

A pinned baseline Transformer implementation (RMSNorm, RoPE, SwiGLU, causal
attention), vendored with its MIT license (see `LICENSE`) so that the systems
benchmarks in `../lm_systems/` measure a fixed model rather than a moving one.
The same architecture is implemented from scratch in
[`../../transformer-lm/`](../../transformer-lm/).
